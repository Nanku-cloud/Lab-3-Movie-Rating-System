# Lab 3 Movie Rating System

A Java console application built for ITSE-2321 that collects user ratings for recent movies, computes average scores, classifies movie taste, and recommends films based on genre preferences.

## Overview

This program demonstrates fundamental Java programming concepts including input validation, parallel arrays, decision-making structures (`if-else`, `switch`), logical operators, and the conditional ternary operator.
